문서 ID: CONSULT-001
제목: 상담 예약 시간 겹침
업무: 업무상담 서비스
점검 유형: logic
적용 상황: 상담 예약 등록이나 변경 시 시간대를 검사하는 코드가 바뀜
점검 방법: 같은 상담사의 기존 예약과 시간이 겹치는지 검사하는 조건을 본다. 시작 시각과 종료 시각의 경계(앞 예약의 종료와 다음 예약의 시작이 같은 경우)를 어떻게 처리하는지 확인한다. 겹침 검사가 시작 시각만 비교하면 지적한다.
예시: 변경 줄: if (existing.start == req.start) reject()  판단: 시작이 다르지만 시간대가 겹치는 예약이 통과한다.
예외: 종료 시각과 시작 시각이 같은 경우를 허용하는 규칙이 diff 에 없으면 확인 필요로 분류한다.
출처: 샘플(가상) 업무 규칙. 사내 실제 규정이 아니며 교육 검증용
