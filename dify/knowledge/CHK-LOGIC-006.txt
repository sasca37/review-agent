문서 ID: CHK-LOGIC-006
제목: 예외 삼킴
점검 유형: logic
적용 상황: try/catch, try/except 가 추가됨
점검 방법: 예외를 잡고 아무 처리 없이 넘기는지 본다. 빈 catch 블록, except 뒤 pass 는 오류를 숨기므로 지적한다. 로그를 남기거나 다시 던지면 지적하지 않는다.
예시: 변경 줄: catch (Exception e) { }  또는  except Exception: pass / 판단: 실패해도 정상 처리된 것처럼 진행된다.
예외: 의도적으로 무시한다는 주석이 같은 줄 근처에 있으면 확인 필요로 분류한다.
출처: 샘플(가상) 팀 규칙. 사내 실제 규정이 아니며 교육 검증용
