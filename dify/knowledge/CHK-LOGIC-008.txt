문서 ID: CHK-LOGIC-008
제목: Java 문자열 및 객체 비교 연산자
점검 유형: logic
적용 상황: Java 코드에서 문자열이나 래퍼 객체를 비교하는 조건식이 추가됨
점검 방법: 문자열을 == 로 비교하면 값이 아니라 참조를 비교한다. equals 를 쓰는지 본다. Integer, Long 같은 래퍼 객체의 == 비교도 같은 문제다.
예시: 변경 줄: if (status == "Y") / 판단: 같은 값이어도 거짓이 될 수 있다. equals 를 사용해야 한다.
예외: 비교 대상이 상수 열거형(enum)이면 지적하지 않는다.
출처: 샘플(가상) 팀 규칙. 사내 실제 규정이 아니며 교육 검증용
