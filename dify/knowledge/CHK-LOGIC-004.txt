문서 ID: CHK-LOGIC-004
제목: 분기 누락 및 반환값 누락
점검 유형: logic
적용 상황: if/else, switch, match 분기나 반환문이 추가·변경됨
점검 방법: 새 분기가 모든 경우를 처리하는지, 일부 경로에서 반환·예외 없이 끝나지 않는지 본다. 새 상태값이나 코드값을 추가했는데 switch 에 case 가 없으면 지적한다.
예시: 변경 줄: if (type == 'A') return 1;  elif (type == 'B') return 2 / 판단: 그 외 값일 때 반환이 없어 None 이 돌아간다.
예외: 나머지 값이 들어올 수 없다는 근거가 diff 에 있으면 지적하지 않는다.
출처: 샘플(가상) 팀 규칙. 사내 실제 규정이 아니며 교육 검증용
