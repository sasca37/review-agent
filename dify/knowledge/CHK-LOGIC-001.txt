문서 ID: CHK-LOGIC-001
제목: 경계값 비교 연산자 점검
점검 유형: logic
적용 상황: 금액·한도·건수·날짜를 비교하는 조건식이 바뀌거나 새로 추가됨
점검 방법: 비교 연산자(> >= < <=)가 주석·메서드명·상수명이 말하는 기준(이상, 초과, 이하, 미만)과 일치하는지 본다. 기준과 연산자가 다르면 지적한다.
예시: 변경 줄: if (amount > 1000000) return 1000;  주석: 100만원 이상 수수료 1000원 / 판단: 100만원 정확히일 때 기준과 다르게 동작한다.
예외: 기준(이상/초과)을 알려 주는 주석·명세가 diff 에 없으면 지적 대신 확인 필요로 분류한다.
출처: 샘플(가상) 팀 규칙. 사내 실제 규정이 아니며 교육 검증용
