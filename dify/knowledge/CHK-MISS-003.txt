문서 ID: CHK-MISS-003
제목: 함께 변경되는 파일 쌍
점검 유형: missing_file
적용 상황: Mapper 인터페이스, 구현 클래스, 설정 파일, SQL 파일처럼 짝이 있는 파일 중 한쪽만 diff 에 있음
점검 방법: 예: XxxMapper.java 와 XxxMapper.xml, 인터페이스와 구현 클래스, 코드값을 추가한 상수 파일과 화면 파일. 한쪽만 있으면 다른 쪽을 확인 필요로 알린다. 샘플(가상) 쌍이며 팀 규칙이 정해지면 교체한다.
예시: 변경 줄: Mapper.java 에 selectFee 메서드 추가, Mapper.xml 은 diff 에 없음 / 판단: 쿼리 정의가 빠졌을 수 있다.
예외: diff 만으로는 짝 파일의 존재와 필요 여부를 알 수 없으므로 항상 확인 필요로 분류한다.
출처: 샘플(가상) 팀 규칙. 사내 실제 규정이 아니며 교육 검증용
