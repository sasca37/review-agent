문서 ID: CHK-TYPO-003
제목: 자주 틀리는 영단어
점검 유형: typo
적용 상황: 새 식별자나 문자열에 영단어가 포함됨
점검 방법: 금융 업무에서 자주 틀리는 단어를 본다. account, amount, balance, transfer, receive, length, address, success, parameter, response, request, password, expired.
예시: 변경 줄: int accout = 0;  String reqeust; / 판단: accout 은 account, reqeust 는 request 의 오타다.
예외: 기존 코드에 같은 철자가 이미 있어 의도된 이름이면 지적 대신 확인 필요로 분류한다.
출처: 샘플(가상) 팀 규칙. 사내 실제 규정이 아니며 교육 검증용
