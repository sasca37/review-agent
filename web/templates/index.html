    최근 리뷰

    업무를 선택하면 이전 요청 기록이 표시됩니다.

      API Key 는 이 브라우저와 점검 서버를 거쳐 Dify 로만 전달되며 화면·로그에 표시하지 않습니다. 입력한 diff 와 점검 결과는 업무별 기록으로 서버에 저장되며, 연결한 Dify 서버로 전송됩니다.

      설정

      점검에 사용할 Dify 워크플로 앱의 주소와 키를 입력하세요. 이 값은 홈 화면에는 표시되지 않습니다.

      ⚙

      API 설정

      Dify 앱 화면 오른쪽 위 'API 접근'에서 확인할 수 있습니다.

      비공개 저장소를 쓰거나 호출 한도(토큰 없이 시간당 60회)에 걸릴 때만 입력하세요. 읽기 권한이면 충분합니다.
      아직 연결을 확인하지 않았습니다.
